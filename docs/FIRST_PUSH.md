# First Push with GitHub Desktop

1. Clone `Battle-Axe-Design-Studio` with GitHub Desktop.
2. Open the cloned repository folder in Windows Explorer.
3. Copy **the contents of this release folder** into the cloned repository folder. Keep the `.github` folder.
4. Return to GitHub Desktop. It should show all new/changed files.
5. Summary: `Battle Axe Design Studio v0.3.2 repository foundation`
6. Click **Commit to main**.
7. Click **Push origin**.
8. On GitHub.com open **Settings → Pages** and select **GitHub Actions** as the Source.
9. Open **Actions**. Wait for `Deploy Battle Axe Design Studio` to turn green.
10. Open the Pages URL. The home diagnostics should show Application Ready, Map Loaded, promoted features, Explorer candidates, and Storage Available.
