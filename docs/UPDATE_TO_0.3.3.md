# Update the live GitHub site to v0.3.3
1. Extract the v0.3.3 release outside the cloned repository folder.
2. Open GitHub Desktop and choose Repository > Show in Explorer.
3. Copy the contents of this release into that repository folder and replace existing files.
4. Return to GitHub Desktop. Review the changed files.
5. Commit with summary: `Battle Axe Design Studio v0.3.3 geometry-first recognition`.
6. Click Push origin.
7. GitHub Actions will automatically build and deploy the site.
8. Wait for the Deploy Battle Axe Design Studio workflow to turn green, then refresh the live site.
