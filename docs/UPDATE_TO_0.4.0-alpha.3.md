# Updating to Battle Axe Design Studio v0.4.0-alpha.4

1. Extract the release outside your cloned GitHub repository.
2. Copy the **contents** of the extracted release folder into the local `Battle-Axe-Design-Studio` repository folder.
3. Replace existing files when Windows asks.
4. Open GitHub Desktop and confirm changed files are listed.
5. Commit as `Battle Axe Design Studio v0.4.0-alpha.4 playtest center`.
6. Push origin.
7. Wait for the GitHub Pages Action to show green build and deploy checks.
8. Hard-refresh the live site if necessary and verify the header reports `v0.4.0-alpha.4`.

The alpha.3 storage key is new so previous alpha browser state is not automatically migrated. This is intentional while the scenario/deployment schema remains in active alpha development.
