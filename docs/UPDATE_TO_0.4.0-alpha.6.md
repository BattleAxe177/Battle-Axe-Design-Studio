# Update to v0.4.0-alpha.6

This release closes the main Map Creator escape-hatch gap and focuses on Scenario Builder usability.

## Manual missing terrain
Use **Add missing feature** on Battlefield Features. Choose polygon, line, or point, draw on the map, finish, name the feature, then classify it with the normal inspector. The source PPTX/PDF/SVG remains unchanged; Studio stores the geometry as reviewed derived terrain.

## Scenario workbench
A checklist now exposes incomplete scenario areas at a glance and links to the relevant workbench stage. Source evidence, Studio suggestions, and accepted design decisions have distinct visual treatments.
