# Update to v0.4.0-alpha.7 — Round-Trip AI & Playtest UX

- Adds Camp and Baggage Train to the canonical Italian Wars library as 40 mm immobile Army Assets; normal roster UI prevents taking both for one side.
- Deployment roster now shows deployed/undeployed status and command-level deployed counts.
- Deployment counters use compact tactical symbols and short IDs; full labels appear on selection/tooltip.
- Replay adds Play/Pause, start/end, timeline stepping and 0.25×–4× playback speed.
- Browser movement now prevents a unit from ending movement overlapping another unit; blocked moves shorten to the nearest clear endpoint.
- Batch results are stored as a concise current playtest summary and included in AI briefs.
- AI Review Bridge now has a separate Designer Request field and mandatory Battle Axe changeset return protocol.
- Pasted structured AI changes are parsed into explicit Accept/Reject cards and applied directly to supported Studio objects only after acceptance. Unstructured replies can still be imported as source/advice.
- Buttons now provide immediate press/working feedback; copy/apply actions provide visible success feedback.
