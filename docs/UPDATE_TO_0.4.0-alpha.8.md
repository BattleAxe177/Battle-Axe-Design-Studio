# Update to v0.4.0-alpha.9

This release adds Playtest Integrity & Scenario Publisher.

Key checks after deployment:
1. Change Game Length in Scenario Builder; Playtest Center should mark itself stale until Reset Playtest is clicked.
2. Run a game involving Defensive terrain and inspect the Battle/Debug log for Armour 6 and defensive first-strike handling.
3. Drag a deployed unit directly with a single click-drag gesture.
4. Add a manual scenario rule and select Automated, Partial, or Tabletop Only.
5. Open AI Review Bridge; the exported brief now includes the Studio object model and mandatory changeset protocol.
6. Open Scenario Publisher; review the compact document and use Export PDF (browser Save as PDF).
